# 昭途考公词语学习系统：平台架构设计

## 1. 目标

在保留现有 Vue 3 前端、Express 后端和可用词库资产的前提下，将系统重构为面向真实用户的移动学习产品。系统只覆盖成语与实词，不包含古诗词。

最终产品必须同时满足：

- 手机优先，并正确适配平板；
- 手机号与微信登录，可跨设备同步；
- 成语、实词词典搜索与可信详情；
- 官媒原文经过自动采集和人工审核后发布；
- 艾宾浩斯记忆学习与个人复习队列；
- 收藏、错题、真题、费曼学习、学习计划、周报和 AI 助手均可用；
- 所有用户界面使用中文；
- 正式内容、AI 草稿、采集原文和用户数据相互隔离。

## 2. 重构边界

### 保留

- Vue 3、TypeScript、Vite、Vue Router；
- Express 作为 HTTP API 服务；
- 现有 SQLite 词库作为迁移输入；
- 经过校验的成语、实词与真题数据；
- 已有功能的产品概念与可复用组件。

### 替换或重写

- 后端单文件路由拆为身份、词典、学习、官媒、统计和审核模块；
- 正式数据库改为 PostgreSQL；
- 客户端 `localStorage` 学习记录迁移为服务端用户数据，本地只保留离线缓存；
- AI 查询时直接写正式词库的逻辑改为进入待审核区；
- 官媒搜索页链接改为真实文章与可核验段落；
- 随机同分类推荐改为结构化近义、反义和易混关系；
- 全部页面采用统一的全中文深蓝紫视觉系统。

## 3. 系统分层

### 移动学习端

单一 Vue 应用同时服务手机和平板，主要模块为：

- 首页与今日任务；
- 成语、实词词典；
- 新词学习；
- 到期复习；
- 真题与错题；
- 收藏、学习报告、费曼学习、AI 助手；
- 登录、账户绑定与设置。

### API 服务

Express 按领域拆分：

- `auth`：短信验证码、微信 OAuth、会话、设备与身份绑定；
- `lexicon`：成语/实词搜索、详情、关系和真题；
- `learning`：学习队列、作答记录、记忆状态和复习调度；
- `media`：已审核官媒引用读取；
- `ingestion`：定向采集、正文解析、去重和链接检查；
- `review-admin`：内容审核、驳回、修订和发布；
- `analytics`：学习事件、周报、连续学习与正确率；
- `ai-assist`：仅生成待审核草稿或回答学习问题。

公开 API 使用 `/api/v1` 版本前缀。后台写入接口要求管理员角色，普通用户不能新增或修改词典与官媒数据。

## 4. 数据与基础设施

### PostgreSQL

保存正式内容和多用户数据，包括：

- 用户、身份、设备和会话；
- 成语、实词、释义、关系和真题；
- 官媒文章、引用段落与审核记录；
- 用户学习计划、记忆状态、作答事件、错题和收藏；
- 内容版本、发布状态和审计日志。

### Redis

用于：

- 短信验证码短期存储；
- 登录和敏感接口限流；
- 官媒采集与解析任务队列；
- 短时缓存。

Redis 不作为唯一数据源，关键状态必须落入 PostgreSQL。

### SQLite

现有 `backend/data/idioms.db` 只作为数据迁移源和迁移前对照，不再承担正式多用户数据写入。迁移过程生成质量报告，脏数据不进入发布态。

## 5. 登录与跨设备同步

### 手机号

- 输入手机号并获取验证码；
- 验证码具有有效期、发送间隔、每日上限和失败锁定；
- 登录后建立安全会话；
- 手机号以规范化形式唯一存储，展示时脱敏。

### 微信

- 微信内使用网页授权；
- 普通浏览器使用微信扫码登录；
- 首次登录创建微信身份；
- 用户可将手机号和微信绑定到同一账户；
- 发现两个已存在账户时进入显式合并流程，不能静默覆盖数据。

### 会话安全

- 使用 `Secure`、`HttpOnly`、`SameSite` Cookie；
- 短访问会话配合可轮换刷新会话；
- 支持主动退出单设备与退出全部设备；
- 敏感操作要求重新验证；
- 不在浏览器存储长期访问令牌。

### 同步策略

服务端是学习状态的最终来源。客户端离线时暂存学习事件，联网后按事件标识去重上传。服务器重新计算记忆状态并返回最新复习队列，避免手机和平板同时学习造成覆盖。

## 6. 数据迁移

迁移分为：

1. 备份并只读打开现有 SQLite；
2. 导出成语、实词、真题和媒体记录；
3. 标记乱码、网页残留、空字段、错误分类与疑似 AI 内容；
4. 规范化拼音、感情色彩、频率和分类；
5. 仅导入通过规则校验的内容；
6. 现有 53 条搜索页形式的“官媒引用”全部进入待审核区，不作为正式官媒原文；
7. 输出迁移数量、拒绝原因和抽样核验报告。

## 7. 安全与隐私

- 立即撤销交接文档中暴露的智谱 API 密钥并重新生成；
- 密钥只通过环境变量或密钥管理服务注入；
- 管理后台实行角色权限与操作审计；
- 采集器只访问配置的官媒域名白名单；
- 对短信、登录、搜索、AI 和采集接口分别限流；
- 数据库使用参数化查询和迁移文件；
- 用户可查看、导出和删除个人学习数据；
- 日志不记录短信验证码、令牌、完整手机号或微信身份凭据。

## 8. 运行与部署

- 本地开发使用容器化 PostgreSQL 与 Redis；
- 前端通过同域 `/api/v1` 访问后端，不硬编码端口；
- 生产环境强制 HTTPS；
- 数据库迁移在部署前执行并可回滚；
- 后台任务与 Web API 进程分离；
- 每日数据库备份，并定期执行恢复演练。

手机号验证码真实发送需要短信服务商账号和签名模板；微信登录需要已认证的微信开放平台或公众号资质、回调域名和密钥。开发环境提供模拟服务，但生产环境只有配置真实资质后才能完成外部登录链路。

## 9. 质量标准

- 未登录用户可浏览词典，学习与跨设备同步要求登录；
- 手机号和微信可绑定同一用户；
- 同一账户在手机和平板上的学习进度一致；
- 普通用户无法调用任何内容发布接口；
- AI 生成内容永远不会绕过人工审核进入正式词库；
- 现有数据迁移有可重复脚本、质量报告和回滚方案；
- 关键 API、身份流程和同步冲突均有自动测试。
