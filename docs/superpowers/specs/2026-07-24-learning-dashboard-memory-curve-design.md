# 首页学习计划与动态记忆曲线设计

## 目标

在不改变现有浅色、移动端优先视觉语言的前提下，解决首页“今日成语挑战”与头部区域重叠的问题，并让学习目标、学习进度、复习计划和艾宾浩斯记忆曲线共享同一份真实用户数据。

## 已确认的问题

1. 首页主内容使用负上边距，挑战卡片覆盖到渐变头部边界。
2. 首页只能查看进度，不能直接调整每日学习目标。
3. 学习计划页仅提供固定档位，无法手动输入任意合理目标。
4. 周学习热力图使用随机数，刷新后变化，不能反映真实学习行为。
5. 两个复习页面的记忆曲线和掌握度分布是静态展示。
6. 新学词语不会自动加入复习队列，学习和复习数据没有闭环。
7. 部分可见按钮没有点击行为，部分返回按钮在直接打开页面时缺少兜底。

## 交互设计

### 首页

- 删除主内容负边距，渐变头部与白色内容区之间保留明确的 16px 间距。
- 在“今日成语挑战”上方增加“今日学习计划”紧凑卡片。
- 卡片提供数字输入框，允许直接键入 1–200；保存后首页进度、学习计划页和学习流程同步更新。
- 保留进入完整“学习计划”页的入口，方便查看今日进度和本周记录。
- 挑战进度来自当天真实答题记录，不再固定显示 0。

### 学习计划页

- 数字输入为主要编辑方式，减号、加号和常用档位作为快捷方式。
- 输入为空或非法时不破坏已保存设置；保存时取 1–200 范围。
- 今日进度使用当天实际新学词数，不再使用历史累计数量。
- 本周热力图按每天实际学习数量显示，不使用随机数。

### 复习页

- 新学成语或实词首次标记为已学时，自动创建第 1 次复习任务。
- 记忆曲线以当前用户全部复习记录实时计算；完成一次复习后立即重绘。
- 无复习记录时显示清晰空状态，不伪造数据。
- “详情”“复习记录”“深度复习”和每条“开始复习”均具有实际跳转。
- 无待复习任务时，深度复习引导用户进入学习页，不生成空词语路由。

### 返回规则

- 页面存在有效应用内历史时使用返回。
- 直接打开深层链接或历史不可用时跳转到该模块的安全首页。
- 学习计划返回首页；复习中心返回复习页；练习页返回来源页或首页。

## 数据模型

`StudyPlan` 增加：

```ts
dailyLearned: Record<string, string[]>
```

- 键为本地日期 `YYYY-MM-DD`。
- 值为当天首次学习的词语列表。
- 旧数据加载时自动补全空对象，保留原有累计 `learned`。

学习目标范围统一为 1–200。

## 艾宾浩斯记忆曲线

复习间隔沿用：

```text
1、2、4、7、15、30 天
```

每条复习记录按当前等级对应的稳定期计算保持率：

```text
retention = 100 × exp(-k × elapsedDays)
k = -ln(0.9) / stabilityDays
```

这使词语在计划复习节点附近保持率约为 90%。总曲线为全部有效复习记录在各观察日的平均值，观察节点为学习日、1、2、4、7、15、30 天。曲线用 Canvas 绘制，避免静态 SVG，并为屏幕阅读器提供文字摘要。

## 视觉约束

- 延续现有浅色背景、白色卡片、蓝紫主色和绿色复习强调色。
- 不增加花哨背景、插画或装饰性资产。
- 触控目标不小于约 44px，数字输入支持移动数字键盘。
- 底部导航与内容保持安全区间距，卡片不被固定导航遮挡。

## 验收标准

- 390×844 和平板宽度下首页无重叠。
- 首页与计划页都能手动输入并保存学习目标，刷新后仍存在。
- 完成新词学习后：今日进度、本周数据、复习队列和曲线同步变化。
- 完成复习后：等级、下次复习时间、掌握分布和曲线立即变化。
- 所有主要可见按钮有结果；主要路径的进入、返回和直接访问均合理。
- 桌面自动化、类型检查、构建和 vivo Android 真机核心流程通过。
