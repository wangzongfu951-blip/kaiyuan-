# 热点词完整词库与 GitHub Pages 公开版设计

## 目标

把当前热点词模块完善为可公开访问的学习页面：默认保持图片中的 22 个热点词、66 条搭配，同时让用户可以切换到现有的 167 个热点词、667 条完整搭配；每条搭配都能点击展开词义、用法与语境、示例、考场功能和易错说明。

## 范围

本次只发布热点词相关文件，不纳入工作区内与热点词无关的未提交文件。热点词公开版使用静态 JSON 和 GitHub Pages，不依赖运行中的 Node/SQLite 服务。现有后端接口继续保留，供本地开发、数据导入和后续服务化使用。

## 数据设计

- `manual_image_seeds.json` 是图片模板的唯一顺序来源，导出 22 个词、66 条搭配。
- SQLite 是当前审校快照的导出源，导出完整库 167 个词、667 条搭配。
- 导出数据保留稳定 ID、热点词、搭配、主题、词义、语境、示例、考场功能和常见误用；年份、来源键等可审计字段可以存在于数据层，但不在模板行或展开卡片中显示。
- 导出前执行必填字段、重复 ID、重复搭配、孤立词条和计数检查；任何失败都使构建失败。
- 不通过批量生成伪造权威原文。现有完整库作为第一版公开数据，后续新材料必须经独立导入与核验后再追加。

## 页面设计

热点页提供两个视图：

1. “图片模板”是默认视图，按图片种子顺序展示 66 条短句，核心热点词使用红色下划线。
2. “完整词库”展示 667 条搭配，支持关键词搜索、主题筛选和分批加载。

两种视图共用搜索和详情交互。点击一行展开学习卡，卡片显示“词义”“用法与语境”“示例”“考场用法”“常见误用”；不显示年份、来源编号或数据库字段。搜索同时匹配热点词、搭配、主题和解释文本；空结果、加载中、导出数据错误均有明确状态。

## 静态数据流

`hotspot-collocations.sqlite` → `hotspots:export` → `public/data/hotspots-image.json` 与 `public/data/hotspots-full.json` → Vue 热点页面。

前端先请求静态 JSON；本地开发如果静态文件缺失，再回退到 `/api/hotspots`。公开构建不要求后端进程，避免 GitHub Pages 上出现 API 代理失败。

## 发布设计

- Vite 构建使用仓库名作为 Pages base，并生成可刷新访问的 SPA 回退页面。
- GitHub Actions 在 `main` 分支变更后自动安装依赖、导出数据、运行数据检查、构建并发布 Pages。
- 页面公开链接形如 `https://<账号>.github.io/<仓库名>/hotspots`；若仓库尚未配置 remote，发布脚本在推送前明确报告所需仓库地址，不猜测账号或仓库。
- 只提交热点模块、静态导出脚本、数据快照、测试、文档和 Pages 工作流；不提交密钥、cookie、数据库以外的临时脚本或与本次无关的未跟踪文件。

## 验收标准

- 导出结果包含 66 条图片模板搭配和 667 条完整搭配，字段检查无错误。
- 图片模板默认顺序从“城乡联动”开始；红色下划线只作用于热点词。
- 完整库切换、搜索、主题筛选、加载更多和点击详情均可用。
- 点击详情能显示五类学习信息，页面不出现年份或来源字段。
- `vue-tsc`、前端生产构建、后端测试、静态导出验证和 Playwright 交互测试全部通过。
- GitHub Actions 构建成功后，Pages 站点可以打开首页和热点页，刷新热点页不返回 404。

## 非目标

- 本次不把整套登录、AI、复习等需要后端状态的功能伪装成 GitHub Pages 静态功能。
- 本次不自动抓取并发布未经人工核验的新权威材料；数据扩充先使用已有 667 条完整快照，后续按核验流程增量导入。
