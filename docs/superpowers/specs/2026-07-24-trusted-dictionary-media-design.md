# 昭途考公词语学习系统：可信词典与官媒设计

## 1. 词典体验

词典只有两个内容类型：成语和实词。用户可以通过词语、拼音、释义关键词、考点和分类搜索。

搜索结果排序依次考虑：

1. 词语完全匹配；
2. 词语前缀匹配；
3. 拼音完全或前缀匹配；
4. 考公高频程度；
5. 释义、考点与分类匹配；
6. 用户近期搜索和学习上下文。

搜索不得因为选择实词分类而把分类文字拼进关键词。无结果时显示建议词和内容缺失状态，不自动向正式库写入 AI 结果。

## 2. 词条详情

### 成语

- 成语、拼音、感情色彩、考公频率和分类；
- 核心释义；
- 正确使用对象、常见搭配与语境；
- 考公易错点；
- 望文生义、对象误用、褒贬误用等考法；
- 现代例句；
- 古籍出处与白话翻译；
- 近义词、反义词和易混成语；
- 真实官媒使用段落；
- 相关真题；
- 收藏、加入学习、问 AI 助手。

### 实词

- 实词、拼音、词性、感情色彩和频率；
- 核心释义；
- 常见搭配、适用对象和语义轻重；
- 考公易错点；
- 现代例句；
- 近义词、反义词和易混实词；
- 真实官媒使用段落；
- 相关真题；
- 收藏、加入学习、问 AI 助手。

没有可信来源的内容明确显示“暂未收录”，不能用生成式文本伪装成官媒原文。

## 3. 结构化词语关系

关系不再通过随机同分类查询生成。每条关系包含：

- 来源词条；
- 目标词条；
- 关系类型：近义、反义、易混；
- 共同点；
- 核心区别；
- 语义轻重；
- 使用对象；
- 常见搭配；
- 感情色彩差异；
- 一个正确对比例句；
- 审核状态与依据。

易混卡片重点回答“什么时候用 A、什么时候用 B”，并可直接进入目标词条。

## 4. 官媒引用数据模型

### 文章

- 官媒名称与规范域名；
- 真实文章标题；
- 作者或来源部门；
- 发布日期；
- 原始 URL 与规范 URL；
- 抓取时间；
- HTTP 状态与最后检查时间；
- 正文哈希，用于识别内容变化；
- 采集状态。

### 引用

- 对应成语或实词；
- 精确引用段落；
- 关键词在段落内的起止位置；
- 前后语境；
- 文章正文中的段落序号；
- 可用时保存 CSS 定位信息；
- 审核人、审核时间、审核结论；
- 发布状态；
- 引用内容哈希。

用户端只展示必要引用片段，不复制整篇受版权保护的文章。

## 5. 原文跳转与定位

优先使用浏览器文本片段链接：

`文章规范地址#:~:text=经过编码的精确引用`

支持文本片段的浏览器会打开原文并高亮对应文字。若官媒页面结构或浏览器不支持文本片段，则：

- 仍跳转真实文章 URL；
- 在跳转前提供“复制定位句”；
- 返回系统后保留原引用段落；
- 显示“打开后可使用页面查找定位”的明确提示。

系统不能承诺所有第三方官媒页面都支持锚点，但必须保证链接指向真实文章而不是搜索结果页。

## 6. 自动采集与人工审核

流程为：

1. 采集器从官媒域名白名单发现文章；
2. 提取标题、时间、作者和正文；
3. 在正文中精确查找成语或实词；
4. 生成包含前后文的候选引用；
5. 对规范 URL、重复文章、正文哈希和关键词位置进行校验；
6. 候选进入审核后台；
7. 审核人员查看原文与引用并通过、修订或驳回；
8. 只有已通过记录可以出现在用户端。

AI 可以辅助判断语境和生成差异摘要，但不能修改原文引用，不能替代审核人，也不能自动发布。

## 7. 审核后台

后台提供：

- 待审核、已通过、已驳回、链接失效和正文变化队列；
- 原文页面与候选引用并排查看；
- 关键词高亮和段落上下文；
- 标题、日期、作者、URL 与域名校验；
- 重复引用提示；
- 批量驳回明显无关候选；
- 单条修订、通过和撤回；
- 所有操作的审计日志。

后台优先为桌面和平板设计，手机仅支持查看和简单审核。

## 8. 数据覆盖策略

功能完整不等于伪造全量数据。内容覆盖按以下顺序扩充：

1. 考公高频成语；
2. 现有真题关联词；
3. 高频实词；
4. 用户高频搜索但缺少证据的词；
5. 其余长尾词。

首页和详情页可展示“已核验官媒引用数量”，不显示虚假的全量覆盖承诺。

## 9. 异常处理

- 文章失效：引用保留审核记录但用户端隐藏跳转；
- 正文发生变化：标记待复核，不自动覆盖已审核文本；
- 同文章多次出现同一词：分别保存段落位置，审核人员决定保留数量；
- 采集被拒绝：记录原因并降低频率，不绕过站点限制；
- 页面只有图片或视频：不生成无法核验的文字引用；
- AI 服务失败：不影响词典和已审核内容访问。

## 10. 验收标准

- 官媒卡片全部指向真实文章；
- 用户看到的引用能在文章正文中找到；
- 支持时跳转后自动高亮定位，不支持时提供定位句；
- 未审核记录不能出现在公开 API；
- 近义、反义和易混词都来自结构化关系；
- 搜索能正确区分成语和实词并支持拼音；
- 随机抽样的词条没有乱码、网页页眉、打印时间或搜索页伪引用；
- 采集、审核、发布、撤回和链接失效均有自动测试。
